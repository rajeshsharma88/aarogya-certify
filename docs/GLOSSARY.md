## Translation Notes

### Formal vs. Casual
- Use **formal Hindi** (शुद्ध हिंदी) for official content
- Use **semi-formal** for instructions and labels
- Avoid colloquial/slang terms in professional context

### Technical Terms
- **Keep English** for widely-recognized technical terms (API, CSS, HTML, UI, UX, etc.)
- Only translate if equivalent exists and is commonly used

### English Loanwords in Hindi
- Common: डैशबोर्ड, प्रोफाइल, स्कोर, डिजिटल, एनालिटिक्स
- These are acceptable and widely understood in India

### Consistency
- Use same term consistently across platform
- If "प्रश्न" used once, use everywhere for "question"
- Check glossary before translating new terms

### Special Characters
- Use proper Devanagari: अ, आ, इ, ई, उ, ऊ, etc.
- Anusvaar (ं) and Visarga (ः) when needed
- Chandrabindu (ँ) for nasal sounds (चाँद)
